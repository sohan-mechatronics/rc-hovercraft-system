# 🚀 RC Hovercraft Prototype

A Remote-Controlled (RC) Hovercraft Prototype developed to demonstrate the principles of air-cushion transportation, wireless control systems, motion control, and mechatronics system integration.

This project combines mechanical design, embedded electronics, propulsion systems, and remote-control technology to create a functional hovercraft capable of moving with minimal surface friction.


## 📖 Project Overview

The RC Hovercraft Prototype is designed to operate on a cushion of air generated by a lift motor. The vehicle is remotely controlled using an RC transmitter and receiver system, allowing wireless maneuverability and directional control.

The project provides practical exposure to:

* Mechatronics Engineering
* Robotics Systems
* Motion Control
* Embedded Electronics
* RC Communication Systems
* Mechanical Design and Prototyping

## ⚙️ Working Principle

### 1️⃣ Lift System

A BLDC motor generates airflow beneath the hovercraft, creating an air cushion between the vehicle and the surface. This significantly reduces friction and enables smooth movement.

### 2️⃣ Propulsion System

A second BLDC motor drives a propeller to generate forward thrust and move the hovercraft.

### 3️⃣ Steering System

A servo motor controls the rudder angle. Steering commands are transmitted wirelessly through the RC transmitter and receiver system.
